# Demo script

A two-minute walkthrough for the video and for live judging. It follows the **Guided tour** button in the header, so the screen does the work: press Next at each cue.

Audience: technical staff, teachers and researchers. Keep the language of the interface: say "rising", "per decade" and "significant", and explain "significant" once.

## Before recording

- Open the deployed link, not a local server (the planet view loads faster there).
- Laptop or projector width. English or Spanish; the tour is in both.
- Run the tour once beforehand so the NASA responses are cached.

## Script

| Time | Tour step | Say | Criterion it serves |
|---|---|---|---|
| 0:00 | (before the tour) | "A municipal technician, a teacher or a researcher sees a claim: it rains more now, it is hotter now. Is it true here, and how sure can we be? That is what this tool answers, with NASA data." | Impact |
| 0:15 | 1. One place, four answers | "Summer rain in the Sahel. One sentence says what is changing, where and how much. The test underneath says whether it could be chance. And this line says what you can state, and what you cannot." | Relevance, validity |
| 0:40 | 2. Which variables indicate change here | "You do not have to know which variable to pick. The tool tests all nine here and ranks them, strongest change first." (Read from the screen how many are changing.) | Relevance (the challenge asks for help selecting variables), creativity |
| 1:00 | 3. Same variable, opposite directions | "Pin the Sahel, open the Congo basin. Same variable, same months, opposite direction, and the tool tests that the two trends really differ. This is the case the challenge describes." | Relevance |
| 1:20 | 4. The planet, not evenly | "Zoom out. The record since 1880, in eight latitude bands, each with its own test." | Validity |
| 1:35 | 5. Where it is heading | "After the last observed year this is not an extrapolation: it is an energy balance model solved on the graphics card, calibrated on the record, with the IPCC range of uncertainty." | Creativity, validity |
| 1:50 | 6. Take the result with you | "A report with method and limits for the technician, the series and the exact NASA request for the researcher, a link for the classroom." | Impact, presentation |

Read the numbers from the screen while recording: they come from live data and can move when NASA publishes a new year.

## What to keep out

- No statistics vocabulary beyond "significant" and "p-value" unless a judge asks; the details panel is there for that.
- Do not claim causes. The tool says a change is real, not why it happens.
- Do not present the planet projection as a climate model forecast; it is a simple physical model, and the interface says so.

## If something fails live

- NASA POWER slow: the status line shows progress and a retry button; keep talking over step 1.
- Planet view empty: the tool falls back to the saved copy of GISTEMP after a few seconds. Skip to step 6 and return.
